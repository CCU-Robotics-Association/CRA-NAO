NAO 机器人验修工具箱 1.0

运行环境
64 位 Windows 10/11，适用于配套 NAOqi 2.8 SDK 的机器人。
程序已包含 Python、Tk 和 NAOqi 通信库，无需安装 Python 或 Conda。

使用方法
1. 将压缩包完整解压到本地目录。
2. 双击 NAO_Toolbox.exe。单文件程序启动时需要解压内置组件，请稍候。
3. 填写机器人编号（例如 01）和 IP 地址，电脑与机器人应处于同一网络。
4. 选择 Quick、Guided 或 Full，点击“开始检查”。录像验收使用 Guided。
5. 完成后点击“打开最近报告”查看结果。

报告默认保存在当前用户的“文档\NAO_Reports”目录，也可在界面中修改。
config.example.json 是可选的配置示例；使用自定义配置时，在界面中选择该文件。

运动检查
关节和行走检查需要单独勾选授权，并按界面提示输入现场安全口令。
操作前请阅读 docs\OPERATOR_CHECKLIST.md。“停止后续项目”按钮不是急停。

故障排查
启动错误日志位于 %LOCALAPPDATA%\NAO_Toolbox\gui_error.log。
可在命令行运行以下命令检查程序内置组件，不连接机器人：
NAO_Toolbox.exe --check-runtime runtime-check.json

本版本未进行数字签名。发布前已检查本机启动及内置组件加载，机器人功能仍需实机验收。
